MANUAL INSTALLATION REQUIRED

How to install

  1. Download the extension ZIP file below.
  2. Extract the ZIP file to a folder on your computer.
  3. Open chrome://extensions in Google Chrome.
  4. Turn on Developer mode.
  5. Select Load unpacked.
  6. Select the extracted dist folder containing manifest.json.

Some desktop-connected features require the SoftFlow desktop app and its native messaging bridge to be installed and configured.
